# Система управления банковскими счетами

Небольшая объектно-ориентированная модель банковского счёта и кредитного счёта на Python. Реализует базовые финансовые операции с валидацией данных и автоматическим ведением истории транзакций.
Возможности

* Базовый счёт (Account): пополнение, снятие средств, проверка баланса.
* Кредитный счёт (CreditAccount): наследует базовый функционал, добавляет поддержку кредитного лимита (возможность уходить в минус).
* История операций: автоматическое логирование всех действий (успешных и неудачных) с временными метками, суммами и статусами.
* Валидация: защита от некорректных операций (отрицательные суммы, превышение лимитов).

## Пример использования

from bank import Account, CreditAccount

**1. Обычный счёт**
acc = Account("Иван Иванов", 1000.0)
acc.deposit(500.0)
acc.withdraw(200.0)
acc.withdraw(5000.0)  # Неудачная операция, баланс не изменится

print(f"Баланс: {acc.get_balance()}")  # 1300.0
print(f"История: {acc.get_history()}")

**2. Кредитный счёт**
credit_acc = CreditAccount("Петр Петров", 0.0, credit_limit=5000.0)
credit_acc.withdraw(1500.0)  # Баланс уйдет в -1500.0

print(f"Доступный кредит: {credit_acc.get_available_credit()}")  # 3500.0

## Структура классов

Account - Базовый класс счёта. Инкапсулирует баланс (_balance) и историю. Методы: deposit(), withdraw(), get_balance(), get_history().

CreditAccount - Наследник Account. Добавляет атрибут credit_limit и переопределяет методы снятия/пополнения с учетом кредитных средств. Метод: get_available_credit()
